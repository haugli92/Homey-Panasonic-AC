# Homey App Store listing

Text to paste into the App Store fields in Homey Developer Tools when
submitting for certification. Kept separate from the repository README so it
can follow the store rules (no URLs, no changelog, short and concise).

## Tagline / description

- **EN:** Smart climate control over infrared
- **NO:** Smart klimastyring over infrarødt

## Readme

**EN**

Turn a Panasonic air conditioner into a proper smart-climate device. Set the
temperature, operating mode and fan speed straight from Homey, and use them in
Flows and schedules.

Everything is sent through Homey's built-in infrared, so no extra hardware or
cloud account is needed — just place Homey within line of sight of the indoor
unit.

**NO**

Gjør et Panasonic-klimaanlegg om til en fullverdig smart klima-enhet. Still
temperatur, driftsmodus og viftehastighet rett fra Homey, og bruk dem i Flows
og tidsplaner.

Alt sendes via Homeys innebygde infrarøde sender, så du trenger verken ekstra
maskinvare eller skykonto — bare plasser Homey med fri sikt til innedelen.
